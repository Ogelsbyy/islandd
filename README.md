# Island — «динамический остров» для Windows

Tauri 2 (Rust) + React/TypeScript. Чёрная пилюля вверху экрана с часами и погодой; при наведении раскрывается в панель.

## Что умеет
- **Пилюля**: время, температура/иконка погоды, эквалайзер при игре музыки, обратный отсчёт таймера
- **Главная**: история буфера обмена (текст и картинки, клик — скопировать снова), скриншот всего экрана (в буфер + `Изображения\Island`), «Чистый текст», быстрый запуск Проводника/PowerShell/Блокнота/Калькулятора/Параметров, громкость
- **Музыка**: трек, исполнитель, прогресс, play/pause/next/prev — через системные медиа-сессии Windows (Spotify, браузер, Яндекс Музыка и т.д.)
- **Погода**: Open-Meteo (без ключа), часовой прогноз, ветер, влажность, давление, УФ, восход/закат; город — авто по IP или вручную
- **Чат**: DeepSeek и Gemini (нужен свой API-ключ в ⚙)
- **Терминал**: PowerShell-команды, `cd`, история ↑/↓; Claude Code — `claude -p "…"`
- **Таймер**: пресеты и свои минуты, тревожное покачивание и сигнал по окончании («Ещё раз» / ✓)
- **Настройки**: цвет острова, прозрачность, город, ключи, папка терминала. Выход — из трея или ⚙.

## Сборка (Windows 10/11)
1. Установи [Node.js 20+](https://nodejs.org), [Rust](https://rustup.rs) и Visual Studio Build Tools (C++ workload). WebView2 уже есть в Windows 11.
2. В папке проекта:
   ```
   npm install
   npm run tauri dev      # запуск для разработки
   npm run tauri build    # установщик: src-tauri/target/release/bundle/nsis/
   ```
Без локальной сборки: залей проект на GitHub и запусти workflow **Build Windows installer** (Actions) — установщик появится в артефактах.

## Известные ограничения MVP
- Скриншот только всего экрана (нет выбора области, текста с экрана, QR, пипетки, записи экрана)
- Обложка трека — градиент-заглушка; громкость — кнопками ±, не ползунком
- Терминал неинтерактивный (нет pty): каждая команда — отдельный процесс
- Нет «персонажей» и жидкой анимации края из видео
- Rust-код проверен `cargo check` на Linux, Windows-часть (PowerShell-вызовы) на реальной Windows ещё не запускалась
